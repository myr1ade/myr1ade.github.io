# Ananya Bongale — Portfolio

An animated editorial portfolio: oversized type, a handwritten red signature, warm paper textures.
Engineering meets expression.

**Live site:** https://myr1ade.github.io/nyvroi.github.io/

## About

Portfolio of Ananya Bongale, a B.Tech Robotics & Automation student at Symbiosis Institute of
Technology, Pune, exploring UI/UX design, creative technology, programming, AI and digital art.

## Built with

React · TypeScript · Vite · Tailwind CSS · Framer Motion

## Run locally

    npm install
    npm run dev

## Edit content

All text, projects and links live in `src/data/portfolio.ts`.
Project images go in `public/images/`. Colors and fonts are at the top of `src/index.css`.

## Deployment

Every push to `main` builds and publishes the site to GitHub Pages automatically.
